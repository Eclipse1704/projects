# סורק מוצרים: תוסף לוורדפרס / WooCommerce

מדביקים קישורים למוצרים מכל אתר, לוחצים **התחל**, וכל מוצר נכנס לחנות **כטיוטה**, מוכן לבדיקה ולפרסום:

- **שם מוצר** בפורמט של החנות, **תיאור מלא** (פסקאות + רשימת שימושים) ו**תיאור קצר**, בעברית טבעית של הענף
- **תמונת מוצר וגלריה**: 3-5 תמונות באיכות מקורית מאתר היצרן הרשמי בלבד, בשמות `MAKER-MODEL-001.jpg`
- **קטגוריה** (מתוך הקטגוריות שכבר יש בחנות), **תגיות**, **מותג**
- **Yoast**: ביטוי מפתח. כותרת SEO, סלאג ותיאור מטא נשארים לוורדפרס ול-Yoast, כמו בשאר המוצרים
- **קטלוג pdf**, **ספר הוראות** (מועלים למדיה) ו**וידאו מוצר** (YouTube מאתר היצרן). השדות של התבנית מזוהים לבד ממוצרים קיימים

## התקנה

1. בניהול האתר: **תוספים ← הוספת תוסף ← העלאת תוסף** ← בוחרים את `product-scraper.zip` ← **התקנה** ← **הפעלה**.
2. **מוצרים ← סורק מוצרים** ← מדביקים מפתח API של Claude (מ-[console.anthropic.com](https://console.anthropic.com/settings/keys)).

צריך WooCommerce פעיל. אין צורך ב-Google, בסיסמאות אפליקציה או בהגדרות נוספות.

## שימוש

1. **מוצרים ← סורק מוצרים** ← מדביקים קישורים (אחד או הרבה) ← **התחל**.
2. כל מוצר עובר: יצרן ← מקור ← עברית ← חנות. אפשר לסגור את הדף, העבודה ממשיכה ברקע.
3. כשמוצר מוכן: **עריכה ופרסום** (הטיוטה בחנות), **תצוגה מקדימה**, או **✏️ תקן טקסט** (Claude כותב מחדש לפי הערה, ומעדכן את אותו מוצר).
4. "מה חסר?" מסביר מה לא נמצא (למשל אין סרטון באתר היצרן).

סריקה חוזרת של אותו קישור מעדכנת את אותו מוצר ולא יוצרת כפילות.

## הגדרות

מהירות (מהיר / חסכוני), מודל (Sonnet / Opus), טיוטה או "ממתין לסקירה", מייל בסיום, מילון מונחים, מילים שלא משתמשים בהן, מוצרים לדוגמה לסגנון (ריק = המוצרים האחרונים בחנות), ושדות מתקדמים.

## טוב לדעת

- **עבודה ברקע** רצה דרך Action Scheduler של WooCommerce. באתרים שבהם WP-Cron כבוי והאתר בלי תנועה, העבודה מתקדמת כשמישהו נכנס לאתר או כשהמסך של הסורק פתוח.
- **שרתים שמנתקים בקשות ארוכות**: התוסף מזהה את זה ועובר לעבודת רקע של Claude (Batches): חצי מחיר, אבל יכול לקחת יותר זמן.
- **עלות**: כ-0.4$ למוצר במצב מהיר, כ-0.2$ במצב חסכוני (Sonnet). העלות מוצגת לכל מוצר ולכל הרצה.
- **הסרה**: מחיקת התוסף מוחקת את הרשימה וההגדרות שלו. המוצרים שנוצרו נשארים בחנות.

## למפתחים

```bash
./build.sh                                   # dist/product-scraper.zip
NPS_WP_DIR=/path/to/wordpress php tests/run.php      # WordPress אמיתי (SQLite) + WooCommerce מדומה, Claude ואתרים מדומים
FAST=0 NPS_WP_DIR=/path/to/wordpress php tests/run.php   # אותו דבר במצב חסכוני (Batches)
```

הבדיקות צריכות התקנת WordPress עם התוסף `sqlite-database-integration` בתיקיית התוספים.
