# סורק מוצרים לווקומרס (תוסף Chrome)

תוסף לדפדפן שסורק מוצרים מאתר של ספק או יצרן, כותב אותם בעברית מקצועית בסגנון של NDT24, ומכין קובץ ייבוא לווקומרס. ככה לא צריך יותר להעתיק ולהדביק כל מוצר בנפרד.

לכל מוצר התוסף מכין:
- **שם מוצר** בסגנון האתר, למשל "מצלמה תרמית 640X480 פיקסלים Fotric 348A"
- **תיאור קצר** של עד 80 מילים
- **תיאור מלא** של עד 500 מילים: סקירה, שימושים, תכונות עיקריות ומפרט טכני, ב-HTML מסודר שגם מודלי שפה (LLM) קוראים בקלות
- **סרטוני YouTube**, רק אם הם מופיעים באתר היצרן הרשמי
- **3-5 תמונות** מאתר היצרן הרשמי, בשמות כמו `FOTRIC-348A-001.jpg`
- **ברושור ומדריך למשתמש (PDF)** מאתר היצרן הרשמי
- **קישורים לדף המוצר** אצל הספק ואצל היצרן

## התקנה (פעם אחת)

1. מורידים את התיקייה `supplier-scraper-extension` למחשב.
2. ב-Chrome פותחים את הכתובת `chrome://extensions`.
3. מדליקים את **Developer mode** (מצב מפתח) בפינה.
4. לוחצים **Load unpacked** ובוחרים את התיקייה `supplier-scraper-extension`.
5. נועצים את התוסף בסרגל (אייקון הפאזל ← סיכה).
6. לוחצים על התוסף בלחיצה ימנית ← **Options**, ומדביקים **מפתח API של Claude**. את המפתח יוצרים ב-[console.anthropic.com](https://console.anthropic.com).

## שימוש

1. נכנסים לאתר של הספק, לדף הקטגוריה או לרשימת המוצרים (למשל `https://us.fotric.com/collections/all-products`).
   באתר של ספק מוכר (Jacobs-MC, Fotric, Riezler, Mitcorp) האייקון של התוסף מקבל סימן ✓ ירוק.
2. לוחצים על התוסף וממלאים או בודקים את השדות:
   - **יצרן**: משמש גם בשמות הקבצים.
   - **אתרים רשמיים של היצרן**: תמונות, קבצים וסרטונים נלקחים רק משם.
   - **סוג המוצרים**: למשל "מצלמות תרמיות". Claude מסנן את כל השאר (אביזרים, חלקי חילוף וכו').
   - **קטגוריה בווקומרס**: למשל `מכשירים לאיתור נזילות מים > מצלמות תרמיות`.
3. לוחצים על **"כל המוצרים מהדף הזה"**, או על **"רק המוצר בדף הזה"** כשנמצאים בדף של מוצר אחד.
4. נפתחת לשונית עם רשימת המוצרים שנמצאו. מסמנים או מבטלים סימון ולוחצים **המשך**.
5. בסוף הכל נשמר בתיקיית ההורדות, תחת `NDT24-import/<ספק>-<תאריך>/`:
   ```
   products.csv   ← קובץ הייבוא לווקומרס
   preview.html   ← תצוגה מקדימה לבדיקה לפני הייבוא
   images/        ← FOTRIC-348A-001.jpg ...
   docs/          ← FOTRIC-348A-BROCHURE.pdf, FOTRIC-348A-MANUAL.pdf
   data.json      ← כל המידע הגולמי והמקורות
   ```

## ייבוא לאתר

1. פותחים את `preview.html` ועוברים על הטקסטים. אם משהו חסר, למשל ברושור או סרטון, זה מסומן בכתום.
2. בוורדפרס נכנסים ל**מוצרים ← ייבוא**, בוחרים את `products.csv` ולוחצים **המשך ← הפעל את הייבוא**.
3. המוצרים נכנסים **כטיוטות**. בודקים, מוסיפים מחיר ומפרסמים. אפשר לשנות את זה בהגדרות.

**תמונות:** כברירת מחדל ווקומרס מוריד את התמונות בזמן הייבוא ישירות מאתר היצרן. אם רוצים שבאתר יופיעו השמות החדשים (`FOTRIC-348A-001.jpg`), מעלים את התיקיות `images` ו-`docs` לתיקייה באתר (למשל דרך FTP ל-`wp-content/uploads/import/`), וכותבים את הכתובת שלה בהגדרות תחת "כתובת תיקיית הקבצים באתר" **לפני** הסריקה.

## איכות העברית

- בהגדרות יש **דפי מוצר לדוגמה מ-NDT24**. התוסף קורא אותם ו-Claude כותב באותו סגנון ובאותם מונחים. אפשר להחליף אותם בדפים אחרים שאוהבים.
- בהגדרות יש גם **מילון מונחים** ("thermal camera = מצלמה תרמית"). מוסיפים אליו כל מונח שיצא לא טוב, והוא ישמש מהסריקה הבאה.
- Claude כותב רק עובדות שמופיעות באתרי הספק והיצרן, ולא ממציא נתונים.
