# סורק מוצרים (תוסף Chrome)

נותנים לתוסף **אתר** ו**סוג מוצר** (למשל "מצלמות תרמיות"), והוא עושה את כל השאר לבד, בכל אתר:

1. סורק את האתר ומוצא את כל המוצרים מהסוג שביקשתם, בלי אביזרים וחלקי חילוף.
2. לכל מוצר מוצא ברשת את היצרן ואת **האתר הרשמי שלו**.
3. מכין לכל מוצר **דף HTML בעברית** במבנה ידידותי ל-LLM, עם:
   - **שם המוצר** בסגנון של NDT24, למשל "מצלמה תרמית 640X480 פיקסלים Fotric 348A"
   - **תיאור קצר** של עד 80 מילים
   - **תיאור מלא** של עד 500 מילים: סקירה, שימושים ואופן שימוש, תכונות ומפרט טכני
   - **קישורים לסרטוני YouTube**, רק מאתר היצרן הרשמי
   - **3-5 תמונות** להורדה, רק מאתר היצרן הרשמי, בשמות כמו `FOTRIC-348A-001.jpg`
   - **ברושור ומדריך למשתמש** להורדה, רק מאתר היצרן הרשמי
   - **קישורים לדף המוצר** באתר הספק ובאתר היצרן
4. מכין גם **קובץ ייבוא לווקומרס** (`products.csv`), כדי להעלות את כל המוצרים לאתר בבת אחת במקום העתק-הדבק.

## התקנה (פעם אחת)

1. מורידים את התיקייה `supplier-scraper-extension` למחשב.
2. ב-Chrome פותחים את הכתובת `chrome://extensions`.
3. מדליקים את **Developer mode** (מצב מפתח) בפינה.
4. לוחצים **Load unpacked** ובוחרים את התיקייה `supplier-scraper-extension`.
5. נועצים את התוסף בסרגל (אייקון הפאזל ← סיכה).
6. לוחצים על התוסף בלחיצה ימנית ← **Options**, ומדביקים **מפתח API של Claude**. את המפתח יוצרים ב-[console.anthropic.com](https://console.anthropic.com).

## שימוש

1. לוחצים על התוסף. אם אתם כבר באתר של הספק, הכתובת שלו מופיעה אוטומטית.
2. כותבים **סוג מוצר**, למשל `מצלמות תרמיות`.
3. לוחצים **התחל**. נפתחת לשונית שמראה את ההתקדמות. אפשר להמשיך לעבוד בינתיים.

בסיום הכל נשמר בתיקיית ההורדות:
```
NDT24-import/<אתר>-<תאריך>/
  index.html                  ← רשימת כל המוצרים, עם הערות על מה שחסר
  products.csv                ← קובץ ייבוא לווקומרס
  FOTRIC-348A/
    FOTRIC-348A.html          ← דף המוצר בעברית
    images/FOTRIC-348A-001.jpg ...
    docs/FOTRIC-348A-BROCHURE.pdf
    docs/FOTRIC-348A-MANUAL.pdf
  data.json                   ← כל המידע הגולמי והמקורות
```

## העלאה לאתר

- **כל המוצרים בבת אחת:** בוורדפרס נכנסים ל**מוצרים ← ייבוא**, בוחרים את `products.csv` ולוחצים **הפעל את הייבוא**. המוצרים נכנסים כטיוטות, ואז בודקים, מוסיפים מחיר ומפרסמים.
- **מוצר בודד:** פותחים את קובץ ה-HTML של המוצר ומעתיקים ממנו.

**תמונות:** כברירת מחדל ווקומרס מוריד את התמונות בזמן הייבוא ישירות מאתר היצרן. אם רוצים שבאתר יופיעו השמות החדשים (`FOTRIC-348A-001.jpg`), מעלים את תיקיית התוצאות לאתר (למשל ל-`wp-content/uploads/import/`), וכותבים את הכתובת בהגדרות תחת "כתובת תיקיית הקבצים באתר" **לפני** הסריקה.

## איכות העברית

- **דוגמאות מהאתר שלכם:** התוסף קורא דפי מוצר קיימים מ-NDT24 (אפשר להחליף אותם בהגדרות), ו-Claude כותב באותו סגנון ובאותם מונחים.
- **מילון מונחים:** בהגדרות יש מילון ("thermal camera = מצלמה תרמית"). מוסיפים אליו כל מונח שיצא לא טוב.
- **רק עובדות מהמקור:** Claude כותב רק מה שמופיע באתר הספק, באתר היצרן ובברושור הרשמי, ולא ממציא נתונים.
