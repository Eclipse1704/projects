# סורק מוצרים ל-Google Drive

אפליקציה קטנה של Google (נפתחת מקישור במחשב, וגם באייפד ובטלפון): מדביקים קישורים למוצרים, לוחצים **התחל**, והמערכת עושה את כל השאר לבד. בסוף כל מוצר מקבל **תיקייה משלו ב-Google Drive**. אין גיליון: הרשימה, ההגדרות והמפתח נשמרים בתוך האפליקציה.

## מה יש בתיקייה של כל מוצר

שם התיקייה בנוי מיצרן, דגם ושם המוצר בעברית, למשל `FOTRIC-348A - מצלמה תרמית 640X480 פיקסלים Fotric 348A`. בתוכה:

```
FOTRIC-348A - מצלמה תרמית 640X480 פיקסלים Fotric 348A/
├── תמונות/
│   ├── FOTRIC-348A-001.jpg      ← התמונה הראשית
│   ├── FOTRIC-348A-002.jpg
│   └── FOTRIC-348A-003.jpg …    ← 3-5 תמונות, באיכות המקורית
├── FOTRIC-348A.html             ← דף המוצר בעברית, במבנה ידידותי ל-LLM (להעברה לאתר)
├── FOTRIC-348A - תיאור          ← אותו תוכן כ-Google Doc, לקריאה נוחה בדרייב
├── FOTRIC-348A-BROCHURE.pdf     ← ברושור
└── FOTRIC-348A-MANUAL.pdf       ← מדריך למשתמש
```

**איכות התמונות:**
- התמונות, הברושור והמדריך נלקחים רק מאתר היצרן הרשמי.
- לכל תמונה המערכת מחפשת את הקובץ המקורי בגודל מלא, ולא את התמונה הממוזערת שמוצגת בדף. היא בודקת את הגרסה שמאחורי קישור או זום, את הגרסה הגדולה ביותר ברשימת הגדלים של התמונה, ואת הכתובת בלי סיומות הקטנה של וורדפרס, Shopify, Wix ו-Squarespace.
- כל תמונה נבדקת לפי הרזולוציה בפועל. תמונה שהצלע הארוכה שלה קצרה מ-800 פיקסלים נחשבת קטנה. היא נכנסת רק אם אין 3 תמונות גדולות, ואז יש עליה הערה באפליקציה ("מה חסר?").
- הרזולוציה של כל תמונה כתובה בדף המוצר.

דף המוצר כולל:
- **שם המוצר**
- **תיאור קצר** של עד 80 מילים
- **תיאור מלא** של עד 500 מילים: סקירה, שימושים ואופן שימוש, תכונות עיקריות ומפרט טכני
- **קישורים לסרטוני YouTube** שמופיעים באתר היצרן הרשמי
- **קישורים לדף המוצר** באתר הספק ובאתר היצרן

## איך זה עובד

1. המערכת פותחת כל קישור.
2. Claude מחפש ברשת מי היצרן ומה האתר הרשמי שלו.
3. המערכת קוראת את דף המוצר באתר היצרן, ומשם בלבד לוקחת תמונות, ברושור, מדריך וסרטונים.
4. Claude כותב את הטקסט בעברית בסגנון של NDT24. הוא קורא דפי מוצר קיימים מ-NDT24 ומשתמש במילון מונחים, כדי שהעברית תהיה כמו שבאמת מדברים בענף ולא תרגום מכונה. הוא כותב רק עובדות שמופיעות אצל הספק, אצל היצרן ובברושור.
5. כל מוצר נשמר בתיקייה משלו, והאפליקציה מראה את השם, היצרן, כפתור לתיקייה והערות על מה שחסר.

העבודה רצה ברקע אצל Google, ואפשר לסגור את הדף ואת המחשב. במצב מהיר (ברירת המחדל) כל המוצרים מעובדים במקביל, ומוצר מוכן בדרך כלל תוך 2-5 דקות מהלחיצה על "התחל". בסוף נשלח אליכם מייל.

## התקנה

**הרעיון:** מישהו אחד (אתה) מתקין פעם אחת ומקבל **קישור**. כל מי שלוחץ על הקישור (אבא, או כל אחד אחר) מאשר הרשאות, וזהו: האפליקציה עובדת אצלו, **בחשבון Google שלו**. המוצרים נשמרים בדרייב שלו, והמפתח, הרשימה וההגדרות שלו נפרדים משלך.

### פעם אחת (מי שמתקין, כ-3 דקות)
1. נכנסים ל-[script.google.com](https://script.google.com) ← **פרויקט חדש (New project)**. למעלה נותנים שם: **סורק מוצרים**.
2. בקובץ `Code.gs` מוחקים הכל ומדביקים את **כל** התוכן של [`install/Code.gs`](install/Code.gs) ← 💾 שמירה.
3. **פריסה (Deploy) ← פריסה חדשה (New deployment)** ← ⚙ **אפליקציית אינטרנט (Web app)**:
   - **הרצה בתור (Execute as):** **המשתמש שניגש לאפליקציה (User accessing the web app)**
   - **למי יש גישה (Who has access):** **כל מי שיש לו חשבון Google (Anyone with Google account)**
   - ← **פריסה (Deploy)**.
4. מעתיקים את **כתובת אפליקציית האינטרנט** (מסתיימת ב-`/exec`). **זה הקישור ששולחים.**

### כל אחד אחר (אבא): לוחץ על הקישור
1. פותחים את הקישור ← **Review permissions** ← בוחרים חשבון ← **Advanced ← Go to סורק מוצרים (unsafe)** ← **Allow**.
   (זו אזהרה רגילה לסקריפט פרטי שלא עבר בדיקה של Google. הוא פונה רק לדרייב של מי שמשתמש בו, לאתרי המוצרים ול-Claude.)
2. האפליקציה נפתחת ומבקשת מפתח API (ההסבר למטה). מדביקים, ומתחילים.
3. **אייקון על שולחן העבודה (Chrome):** ⋮ ← **שמירה ושיתוף ← יצירת קיצור דרך** ← מסמנים **פתיחה כחלון** ← יצירה.
   באייפד/אייפון: **שיתוף ← הוספה למסך הבית**.

**עדכון גרסה (רק מי שהתקין):** מדביקים את הקוד החדש ← שמירה ← **פריסה ← ניהול פריסות (Manage deployments)** ← ✏️ ← **גרסה: גרסה חדשה** ← פריסה. הקישור לא משתנה, וכולם מקבלים את העדכון לבד.

### מפתח API של Claude (פעם אחת)
1. [console.anthropic.com](https://console.anthropic.com) ← נרשמים.
2. **Billing** ← טוענים קרדיט (לניסיון 10$). מומלץ להגדיר גם תקרה ב-**Limits**.
3. **API Keys** ← **Create Key** ← מעתיקים (`sk-ant-...`).
4. בפעם הראשונה שפותחים את האפליקציה היא מבקשת את המפתח. מדביקים ולוחצים "שמור מפתח". המערכת בודקת שהוא תקין.

## שימוש

1. פותחים את האפליקציה ומדביקים **קישורים** בתיבה, אחד או הרבה. אפשר גם טקסט חופשי עם קישורים בתוכו, והמערכת מוצאת אותם לבד. לוחצים **▶ התחל**.
2. **מתחת לתיבה** רואים כל מוצר עם פס התקדמות: יצרן ← אתר ← עברית ← דרייב ← **מוכן**.
3. **כשמוצר מוכן** לוחצים **📁 פתח תיקייה**. אם חסר משהו (למשל אין ברושור באתר היצרן), לוחצים "מה חסר?".
4. בסוף הרשימה: **"נקה מוצרים שהסתיימו"** (התיקיות בדרייב נשארות) ו**"עצור הכל"** (לחיצה כפולה).

אפשר לסגור את הדף, והעבודה ממשיכה ברקע. בסיום נשלח מייל עם קישור לאפליקציה.

## הגדרות (כפתור ⚙ הגדרות למעלה)

- **מהירות:** מהיר (ברירת מחדל) = Claude עונה מיד, והמוצרים מוכנים תוך דקות. חסכוני = עבודת רקע של Claude: חצי מחיר, אבל יכול לקחת עד שעה.
- **מודל:** Sonnet (ברירת מחדל) או Opus (חזק יותר, יקר פי 2.5).
- **תיקייה בדרייב:** שם התיקייה הראשית. ברירת מחדל: `NDT24 - מוצרים`.
- **מייל כשהסריקה מסתיימת:** כן / לא.
- **מילון מונחים:** שורה לכל מונח, למשל `borescope = בורוסקופ`. אם מילה יוצאת לא טוב, מוסיפים אותה כאן, והיא תשמש מהסריקה הבאה.
- **מילים שלא משתמשים בהן:** מילה או ביטוי בכל שורה (למשל "הינו", "פתרון מושלם"). אם Claude משתמש באחת מהן, הטקסט חוזר אליו לתיקון.
- **דפי דוגמה לסגנון:** דפי מוצר מ-NDT24 ש-Claude לומד מהם איך כותבים. אפשר להחליף בדפים אחרים שאוהבים.
- **מפתח API:** החלפת המפתח. יש גם כפתור "החזר הגדרות ברירת מחדל".

## טוב לדעת

- **פריטים חסרים:** אם באתר היצרן אין סרטון, ברושור או מספיק תמונות, המערכת לא לוקחת אותם מאתרים אחרים. זה כתוב ב"מה חסר?".
- **"לא ניתן לפתוח את הקובץ" כשפותחים את האפליקציה:** קורה כשמחוברים בדפדפן לכמה חשבונות Google. פותחים את הקישור בחלון גלישה בסתר ומתחברים רק לחשבון שהתקין, או מתנתקים מהחשבונות האחרים.
- **עלות:** לפי כמות המוצרים. עם Sonnet: כ-0.4$ למוצר במצב מהיר, כ-0.2$ כשמצב מהיר כבוי.
- **אתרים שבנויים ב-JavaScript:** אתרים שבונים את הדף רק בדפדפן עלולים להיקרא חלקית. במקרה כזה Claude עדיין מוצא את המידע דרך החיפוש שלו, אבל ייתכן שיהיו פחות תמונות.

## בדיקות (למפתחים)

אחרי כל שינוי בקבצי ה-`.gs` מריצים `./build.sh` כדי לעדכן את `install/Code.gs`. (`appsscript.json` לא חובה: Apps Script מזהה את ההרשאות לבד.)

```bash
node tests/test.mjs         # כל התהליך מול Google, אתרים ו-Claude מדומים
node tests/robustness.mjs   # 42 תרחישי תקלה, איכות, מהירות, התקנה והאפליקציה (FAST=1 = במצב מהיר): מפתח שגוי, עומס ב-Claude, אתר איטי/למטה, הפניות,
                            # 400 קישורים, קבצים באשפה, עצירה באמצע, ועוד
```
