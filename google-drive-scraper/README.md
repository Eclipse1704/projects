# סורק מוצרים ל-Google Drive

מדביקים קישורים למוצרים בגיליון Google, לוחצים **הרץ**, והמערכת עושה את כל השאר לבד. בסוף כל מוצר מקבל **תיקייה משלו ב-Google Drive**.

## מה יש בתיקייה של כל מוצר

שם התיקייה בנוי מיצרן, דגם ושם המוצר בעברית, למשל `FOTRIC-348A - מצלמה תרמית 640X480 פיקסלים Fotric 348A`. בתוכה:

```
FOTRIC-348A - מצלמה תרמית 640X480 פיקסלים Fotric 348A/
├── תמונות/
│   ├── FOTRIC-348A-001.jpg      ← התמונה הראשית
│   ├── FOTRIC-348A-002.jpg
│   └── FOTRIC-348A-003.jpg …    ← 3-5 תמונות, באיכות המקורית
├── FOTRIC-348A.html             ← דף המוצר בעברית, במבנה ידידותי ל-LLM (להעברה לאתר)
├── FOTRIC-348A - תיאור          ← אותו תוכן כ-Google Doc, לקריאה נוחה בדרייב
├── FOTRIC-348A-BROCHURE.pdf     ← ברושור
└── FOTRIC-348A-MANUAL.pdf       ← מדריך למשתמש
```

**איכות התמונות:**
- התמונות, הברושור והמדריך נלקחים רק מאתר היצרן הרשמי.
- לכל תמונה המערכת מחפשת את הקובץ המקורי בגודל מלא, ולא את התמונה הממוזערת שמוצגת בדף. היא בודקת את הגרסה שמאחורי קישור או זום, את הגרסה הגדולה ביותר ברשימת הגדלים של התמונה, ואת הכתובת בלי סיומות הקטנה של וורדפרס, Shopify, Wix ו-Squarespace.
- כל תמונה נבדקת לפי הרזולוציה בפועל. תמונה שהצלע הארוכה שלה קצרה מ-800 פיקסלים נחשבת קטנה. היא נכנסת רק אם אין 3 תמונות גדולות, ואז יש עליה הערה בגיליון.
- הרזולוציה של כל תמונה כתובה בדף המוצר.

דף המוצר כולל:
- **שם המוצר**
- **תיאור קצר** של עד 80 מילים
- **תיאור מלא** של עד 500 מילים: סקירה, שימושים ואופן שימוש, תכונות עיקריות ומפרט טכני
- **קישורים לסרטוני YouTube** שמופיעים באתר היצרן הרשמי
- **קישורים לדף המוצר** באתר הספק ובאתר היצרן

## איך זה עובד

1. המערכת פותחת כל קישור.
2. Claude מחפש ברשת מי היצרן ומה האתר הרשמי שלו.
3. המערכת קוראת את דף המוצר באתר היצרן, ומשם בלבד לוקחת תמונות, ברושור, מדריך וסרטונים.
4. Claude כותב את הטקסט בעברית בסגנון של NDT24. הוא קורא דפי מוצר קיימים מ-NDT24 ומשתמש במילון מונחים, כדי שהעברית תהיה כמו שבאמת מדברים בענף ולא תרגום מכונה. הוא כותב רק עובדות שמופיעות אצל הספק, אצל היצרן ובברושור.
5. כל מוצר נשמר בתיקייה משלו, והגיליון מתעדכן: סטטוס, שם המוצר, יצרן, קישור לתיקייה, והערות על מה שחסר.

העבודה רצה ברקע, ואפשר לסגור את הגיליון. במצב מהיר (ברירת המחדל) כל המוצרים מעובדים במקביל, ומוצר מוכן בדרך כלל תוך 2-5 דקות מהלחיצה על "הרץ". בסוף נשלח אליכם מייל.

## התקנה (פעם אחת, כ-15 דקות)

צריך: מחשב, חשבון Google, ושני קבצים מהתיקייה `install`: **`Code.gs`** ו-**`appsscript.json`**.

**א. מפתח API של Claude**
1. נכנסים ל-[console.anthropic.com](https://console.anthropic.com) ונרשמים.
2. **Billing** ← טוענים קרדיט (לניסיון מספיקים 10$). מומלץ להגדיר גם תקרה חודשית ב-**Limits**.
3. **API Keys** ← **Create Key** ← מעתיקים את המפתח (`sk-ant-...`) ושומרים בצד.

**ב. גיליון והקוד**
4. נכנסים ל-[sheets.new](https://sheets.new) ונותנים לגיליון שם, למשל "סורק מוצרים".
5. בתפריט: **תוספים (Extensions) ← Apps Script**.
6. בעורך פתוח קובץ `Code.gs`. מוחקים את כל מה שכתוב בו ומדביקים את **כל** התוכן של `install/Code.gs`.
7. ⚙️ **Project Settings** ← מסמנים **Show "appsscript.json" manifest file in editor**.
8. חוזרים לעורך (`< >`), פותחים את `appsscript.json`, מוחקים הכל ומדביקים את התוכן של `install/appsscript.json`.
9. 💾 **שמירה**.

**ג. הפעלה**
10. חוזרים לגיליון ומרעננים (F5). מופיע תפריט **סורק מוצרים**.
11. **סורק מוצרים ← הגדרת מפתח API של Claude**.
12. אישור הרשאות (פעם אחת): **Continue** ← בוחרים חשבון ← "Google hasn't verified this app" ← **Advanced** ← **Go to … (unsafe)** ← **Allow**. זה מופיע כי הסקריפט שלכם ולא של Google.
13. מדביקים את המפתח ← OK. אם אחרי האישור לא נפתח חלון המפתח, בוחרים שוב בתפריט **הגדרת מפתח API של Claude**.

## שימוש

1. בגיליון **מוצרים**, בעמודה **קישור למוצר**, מדביקים קישור אחד בכל שורה. אפשר כמה מוצרים שרוצים, מכל אתר.
2. **סורק מוצרים ← ▶ הרץ על הקישורים**.
3. עמודת הסטטוס מתעדכנת לבד. כשמוצר מוכן מופיע "✓ הושלם" וקישור **פתח תיקייה**.

- **מוצרים חדשים:** מוסיפים שורות ומריצים שוב. רק השורות החדשות ירוצו.
- **הרצה מחדש של מוצר:** מוחקים את הסטטוס שלו ומריצים שוב. התיקייה שלו תתעדכן.
- **עצירה:** **סורק מוצרים ← ■ עצור**.

## הגדרות (בגיליון "הגדרות")

- **תיקייה בדרייב:** שם התיקייה הראשית. ברירת מחדל: `NDT24 - מוצרים`.
- **דפי דוגמה לסגנון:** דפי מוצר מ-NDT24 ש-Claude לומד מהם איך כותבים. אפשר להחליף בדפים אחרים שאוהבים.
- **מילון מונחים:** שורה לכל מונח, למשל `borescope = בורוסקופ`. אם מילה יוצאת לא טוב, מוסיפים אותה כאן, והיא תשמש מהסריקה הבאה.
- **מילים שלא משתמשים בהן:** מילה או ביטוי בכל שורה (למשל "הינו", "פתרון מושלם"). אם Claude משתמש באחת מהן, הטקסט חוזר אליו לתיקון.
- **מצב מהיר:** `כן` (ברירת מחדל) = Claude עונה מיד, והמוצרים מוכנים תוך דקות. `לא` = עבודת רקע של Claude: חצי מחיר, אבל יכול לקחת עד שעה.
- **מודל:** `claude-sonnet-5` (ברירת מחדל) או `claude-opus-5` (חזק יותר, יקר פי 2.5).
- **שליחת מייל בסיום:** כן / לא.

## טוב לדעת

- **פריטים חסרים:** אם באתר היצרן אין סרטון, ברושור או מספיק תמונות, המערכת לא לוקחת אותם מאתרים אחרים. זה כתוב בעמודת ההערות.
- **עלות:** לפי כמות המוצרים. עם Sonnet: כ-0.4$ למוצר במצב מהיר, כ-0.2$ כשמצב מהיר כבוי.
- **אתרים שבנויים ב-JavaScript:** אתרים שבונים את הדף רק בדפדפן עלולים להיקרא חלקית. במקרה כזה Claude עדיין מוצא את המידע דרך החיפוש שלו, אבל ייתכן שיהיו פחות תמונות.

## בדיקות (למפתחים)

אחרי כל שינוי בקבצי ה-`.gs` מריצים `./build.sh` כדי לעדכן את `install/Code.gs`.

```bash
node tests/test.mjs         # כל התהליך מול Google, אתרים ו-Claude מדומים
node tests/robustness.mjs   # 32 תרחישי תקלה, איכות ומהירות (FAST=1 = במצב מהיר): מפתח שגוי, עומס ב-Claude, אתר איטי/למטה, הפניות,
                            # 400 קישורים, קבצים באשפה, עצירה באמצע, ועוד
```
